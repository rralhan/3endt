# 3endt

3endt is a modernized .NET web application for managing product, inventory, and commerce-related data for 3endt.com.

This repository replaces the original legacy ASP.NET Web Forms application with a cleaner layered architecture built around modern .NET development practices.

## Solution Structure

- **3endt** - Main web application
- **3endt.Service** - Application and business services
- **3endt.Data** - Data access layer
- **3endt.Models** - Domain models and data transfer objects
- **3endt.Configuration** - Application configuration
- **3endt.Common** - Shared utilities and common components
